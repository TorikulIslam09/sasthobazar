স্বাস্থ্যবাজার (SasthoBazar) — মাল্টি-ভেন্ডর ই-কমার্স + বিজনেস ম্যানেজমেন্ট সিস্টেম
==========================================================================
ভার্সন: PHP + MySQL (XAMPP)

এটি আগের স্ট্যাটিক ভার্সনের (index.html, admin.html, db.js, localStorage) পরিবর্তে
Raw PHP 8 + PDO + MySQL দিয়ে বানানো পূর্ণাঙ্গ ভার্সন। এখন ডেটা ডাটাবেসে সংরক্ষিত
হয়, তাই একাধিক কাস্টমার, ভেন্ডর ও কর্মচারী একসাথে কাজ করতে পারবে।


১. প্রয়োজনীয় সফটওয়্যার
------------------------
  - XAMPP (PHP 8.0 বা তার বেশি, Apache, MySQL/MariaDB)
  - আধুনিক ব্রাউজার (Chrome / Edge / Firefox)


২. ফোল্ডার স্ট্রাকচার
----------------------
  /config        → ডাটাবেস ও সাইট কনফিগারেশন
  /core          → Router, Database, Auth, CSRF, Helpers
  /app
     /controllers
     /models
     /views
  /public        → index.php, assets (css/js/images), uploads
  /admin         → সুপার অ্যাডমিন ও কর্মচারী প্যানেল
  /vendor-panel  → ভেন্ডর প্যানেল
  /database      → schema.sql ও seed.sql
  /install       → ইনস্টলার
  /storage       → প্রাইভেট ফাইল (প্রেসক্রিপশন, ভেন্ডরের ডকুমেন্ট), ওয়েব থেকে সরাসরি খোলা যায় না


৩. ইনস্টল করার নিয়ম (XAMPP)
---------------------------
  ১) প্রজেক্ট ফোল্ডারটি C:\xampp\htdocs\shasthobazar এ রাখুন।
     (ফোল্ডারের নাম যা দেবেন, ব্রাউজারের URL ও config-এর base URL তা-ই হতে হবে)
  ২) XAMPP Control Panel থেকে Apache ও MySQL চালু করুন।
  ৩) ব্রাউজারে খুলুন:  http://localhost/shasthobazar/install
  ৪) ডাটাবেসের তথ্য দিন (সাধারণত host: localhost, user: root, password: খালি)।
     ইনস্টলার ডাটাবেস তৈরি করে schema.sql ও seed.sql চালাবে।
  ৫) ইনস্টল শেষ হলে /install ফোল্ডারটি মুছে ফেলুন বা নাম বদলে দিন (নিরাপত্তার জন্য জরুরি)।


৪. গুরুত্বপূর্ণ লিংক
--------------------
  কাস্টমার সাইট      : http://localhost/shasthobazar/
  কাস্টমার লগইন      : http://localhost/shasthobazar/login
  অ্যাডমিন প্যানেল    : http://localhost/shasthobazar/admin
  ভেন্ডর প্যানেল      : http://localhost/shasthobazar/vendor-panel


৫. ডিফল্ট লগইন (ইনস্টলের পরেই বদলে নিন)
-----------------------------------------
  সুপার অ্যাডমিন : ইনস্টলারে বা seed.sql-এ যে ইমেইল/পাসওয়ার্ড দেওয়া আছে সেটি ব্যবহার করুন।
                   প্রথম লগইনের পরেই পাসওয়ার্ড পরিবর্তন করুন।

  ডেমো কাস্টমার  : মোবাইল 01711000000 / পাসওয়ার্ড 1234

  ডেমো কুপন
    WELCOME10  → ৫০০ টাকার বেশি অর্ডারে
    FLAT50     → ৮০০ টাকার বেশি অর্ডারে


৬. ইউজার রোল
-------------
  সুপার অ্যাডমিন : পুরো সিস্টেমের নিয়ন্ত্রণ, রোল ও পারমিশন, ভেন্ডর অনুমোদন, সেটিংস
  কর্মচারী        : সুপার অ্যাডমিনের তৈরি কাস্টম রোল (Manager, Order Processor,
                   Inventory Officer, Accountant, Support ইত্যাদি), মডিউলভিত্তিক পারমিশন
  ভেন্ডর          : নিজের আলাদা লগইন, শুধু নিজের পণ্য/অর্ডার/রিপোর্ট দেখতে পারবে
  কাস্টমার        : রেজিস্টার্ড ইউজার অথবা গেস্ট (শুধু মোবাইল বা ইমেইল দিয়ে অর্ডার)


৭. মূল ফিচার
-------------
  - মাল্টি-ভেন্ডর (ফার্মেসি, মেডিকেল স্টোর, বিউটি, গ্রোসারি, বেবি কেয়ার ইত্যাদি)
  - ভেন্ডরভিত্তিক কমিশন (ডিফল্ট ৮%), অগ্রাধিকার: পণ্য > ক্যাটাগরি > ভেন্ডর টাইপ > ভেন্ডর > গ্লোবাল
  - প্রেসক্রিপশন আপলোড ও ফার্মাসিস্ট ভেরিফিকেশন
  - গেস্ট চেকআউট, কাস্টমার ড্যাশবোর্ড, অর্ডার বাতিল, রিটার্ন/রিফান্ড
  - পেমেন্ট: ক্যাশ অন ডেলিভারি, bKash/Nagad/Rocket (TrxID), SSLCommerz/aamarPay
  - বাংলাদেশ শিপিং: ৮ বিভাগ, ৬৪ জেলা, উপজেলা, জোনভিত্তিক চার্জ, কুরিয়ার অ্যাডাপ্টার, COD সেটলমেন্ট
  - ইনভেন্টরি: ব্যাচ, এক্সপায়ারি, লো-স্টক ও আউট-অফ-স্টক সতর্কতা
  - অফার: কুপন, ফ্ল্যাশ সেল, বান্ডেল, ফ্রি ডেলিভারি থ্রেশহোল্ড
  - রিভিউ ও রেটিং, হোম পেজে কাস্টমার রিভিউ সেকশন
  - রিপোর্ট ও একাউন্টিং (CSV/Excel/PDF এক্সপোর্ট)
  - অডিট লগ, অ্যাডমিন নোটিফিকেশন

৯. বাংলা লেখা ??? দেখালে (এনকোডিং সমস্যা)
------------------------------------------
  - PDO ডাটাবেস কানেকশনে charset=utf8mb4 থাকতে হবে।
  - ডাটাবেস ও টেবিল utf8mb4_unicode_ci হতে হবে।
  - সব PHP/SQL ফাইল UTF-8 (BOM ছাড়া) হিসেবে সেভ করতে হবে।
  - phpMyAdmin-এ ইমপোর্টের সময় Character set: utf8mb4 বেছে নিন।
  - আগেই "???" হিসেবে সেভ হয়ে যাওয়া ডেটা ফেরত আসে না, নতুন করে ইমপোর্ট করতে হবে।


১০. ব্যাকআপ
------------
  - Admin > Settings > Backup থেকে ডাটাবেস ব্যাকআপ ডাউনলোড করুন।
  - /storage ও /public/uploads ফোল্ডারও আলাদা করে কপি করে রাখুন।
  - নিয়মিত (অন্তত সাপ্তাহিক) ব্যাকআপ নিন।


১১. অনলাইনে লাইভ করার আগে
--------------------------
  - /install ফোল্ডার মুছে ফেলুন।
  - সব ডিফল্ট পাসওয়ার্ড বদলান, ডেমো ডেটা ও ডেমো কাস্টমার মুছুন।
  - HTTPS (SSL) চালু করুন।
  - config ফাইলে debug/error display বন্ধ করুন।
  - /config, /database, /storage ফোল্ডারে ওয়েব থেকে সরাসরি অ্যাক্সেস বন্ধ আছে কি না যাচাই করুন।
  - bKash, SSLCommerz, কুরিয়ার ও SMS-এর জন্য আলাদা মার্চেন্ট/API অ্যাকাউন্ট নিয়ে
    Admin > Settings-এ কী বসান।
  - ওষুধ বিক্রির জন্য বাংলাদেশে DGDA ড্রাগ লাইসেন্স ও প্রেসক্রিপশন নিয়ম মানা বাধ্যতামূলক।


১২. সমস্যা হলে
---------------
  - পেজ না খুললে: Apache ও MySQL চালু আছে কি না দেখুন।
  - ডাটাবেস এরর: config ফাইলের host/user/password যাচাই করুন।
  - ছবি আপলোড হচ্ছে না: /public/uploads ও /storage ফোল্ডারের রাইট পারমিশন দেখুন,
    এবং php.ini-তে upload_max_filesize ও post_max_size বাড়ান।
  - এরর লগ: C:\xampp\apache\logs\error.log
