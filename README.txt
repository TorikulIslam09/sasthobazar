# স্বাস্থ্যবাজার — ই-কমার্স সাইট + ম্যানেজমেন্ট প্যানেল

## ফাইলসমূহ

- `index.html` → কাস্টমারদের ওয়েবসাইট (সব পেজ)
- `admin.html` → অ্যাডমিন / ম্যানেজমেন্ট ড্যাশবোর্ড
- `db.js` → দুটোর শেয়ার্ড ডেটা (এই ফাইল অবশ্যই একই ফোল্ডারে রাখতে হবে)

## চালানোর নিয়ম

তিনটি ফাইল একই ফোল্ডারে রেখে Chrome-এ `index.html` খুলুন।

অ্যাডমিন প্যানেল: `admin.html` খুলুন।  
পাসওয়ার্ড: `admin123`

(সেটিংস → নিরাপত্তা থেকে পাসওয়ার্ড পরিবর্তন করে নিন।)

দুটো আলাদা ট্যাবে খুললে অ্যাডমিনে করা যেকোনো পরিবর্তন সাইটে সাথে সাথে দেখা যাবে, আর সাইটে নতুন অর্ডার এলে অ্যাডমিনে নোটিফিকেশন আসবে।

**ডেমো কাস্টমার লগইন:**
- মোবাইল: `01711000000`
- পাসওয়ার্ড: `1234`

**ডেমো কুপন:**
- `WELCOME10` — ৫০০ টাকার বেশি অর্ডারে
- `FLAT50` — ৮০০ টাকার বেশি অর্ডারে

## গুরুত্বপূর্ণ

এই ভার্সনে ডেটা ব্রাউজারের `localStorage`-এ থাকে — অর্থাৎ শুধু একই কম্পিউটার ও একই ব্রাউজারে কাজ করে।

অনলাইনে লাইভ করে বিভিন্ন কাস্টমারের অর্ডার নিতে হলে একটি সার্ভার/ডাটাবেস (যেমন Node.js, PHP + MySQL বা Firebase) লাগবে।

`db.js`-এর `load()` ও `save()` ফাংশন দুটো API কল দিয়ে বদলালেই বাকি সব কোড একই থাকবে।

নিয়মিত অ্যাডমিন → ব্যাকআপ থেকে ডেটা ডাউনলোড করে রাখুন।
